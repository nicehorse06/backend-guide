# prompt template

You are my technical coach helping me prepare for backend engineering interviews.  
I will provide you with a topic (for example, "Linux Networking" or "Python GIL").  

Please generate a structured interview summary in the following format:

## <Topic Name>

### 🧩 Keywords
List the key technical terms and concepts related to this topic, organized in a clear hierarchy (use Markdown).

### 💬 Common Interview Questions
List frequently asked interview questions, including conceptual ("Why"), implementation ("How"), and comparison-style ("Compare") questions.

### ⚙️ Practical Insights
Describe how this topic is applied in real-world backend development.  
Include common pitfalls, debugging tips, and best practices.

### 🚀 Advanced / Extended Topics (optional)
If applicable, include advanced directions for further learning (e.g., optimization, scalability, cloud-specific aspects).

---

**Output Requirements:**
- Use **Markdown** formatting.
- Be concise but cover all key concepts.
- No unnecessary API-level or syntax details.
- The summary should serve as a **3-minute pre-interview refresher**.
- If I add “Give me the quick version,” include a short **5-line summary** at the end.
